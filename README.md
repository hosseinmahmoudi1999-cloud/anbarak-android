# انبارک — نسخه ۳ با رابط کاربری بهبودیافته

- اپلیکیشن اندروید فارسی و راست‌چین
- آفلاین با پایگاه داده محلی SQLite
- چند انبار مستقل و انتقال کالا بین انبارها
- تعریف و ویرایش کالا، موجودی هر انبار، ورود، خروج و گردش اسناد
- داشبورد خلوت با شمارنده‌های متحرک، نمودارهای متحرک ورود و خروج و جابه‌جایی نرم بین صفحات
- ساخت APK با GitHub Actions

## ساخت APK
فایل‌های این پروژه را در ریشه مخزن GitHub قرار دهید و Commit کنید. گردش کار `.github/workflows/build-apk.yml` به‌صورت خودکار اجرا می‌شود. پس از موفقیت، در صفحه اجرای Actions بخش Artifacts فایل `anbarak-debug-apk` را دانلود کنید و ZIP آن را استخراج کنید تا `app-debug.apk` به دست آید.

نکته: این نسخه در محیط فعلی به‌صورت محلی کامپایل نشده است؛ تأیید نهایی کامپایل را باید نتیجه GitHub Actions انجام دهد.
