# انبارک (Anbarak)

اپلیکیشن آزمایشی اندرویدی برای ثبت کالا و گردش موجودی، با ذخیره‌سازی محلی و بدون نیاز به اینترنت در زمان استفاده.

## امکانات نسخه اولیه
- افزودن کالا و تعیین حداقل موجودی
- مشاهده فهرست کالاها
- ثبت ورود و خروج
- جلوگیری از خروج بیشتر از موجودی فعلی
- ذخیره داده‌ها روی خود دستگاه با SQLite

## ساخت APK با GitHub Actions
پس از بارگذاری این پروژه در مخزن GitHub:
1. وارد تب **Actions** شو.
2. در صورت درخواست، گزینه فعال‌سازی workflow را بزن.
3. اجرای **Build Anbarak APK** را انتخاب کن و روی **Run workflow** بزن.
4. بعد از موفقیت، در صفحه اجرای workflow به بخش **Artifacts** برو و `anbarak-debug-apk` را دانلود کن.
5. ZIP دانلودشده را استخراج کن؛ فایل `app-debug.apk` داخل آن است.

این نسخه اولیه است و هنوز امکاناتی مانند ویرایش/حذف کالا، گزارش گردش، خروجی CSV، پشتیبان‌گیری و بازیابی ندارد. قبل از استفاده عملی، داده‌های آزمایشی وارد و رفتار برنامه بررسی شود.
